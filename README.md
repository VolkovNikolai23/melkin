# Мелькин <3

Учебное приложение для iPad в духе RemNote, без подписок: конспекты-тетрадки с Apple Pencil, презентации (PDF) с пометками, карточки и интервальное повторение. Полное ТЗ — `SPEC.md`, план и статус — `docs/PLAN.md`. Всё хранится в IndexedDB на устройстве, после первой загрузки работает офлайн.

## Как устроено

- **Предмет → Тема → Лекция.** «+ Предмет» внизу боковой панели; в меню «⋯» предмета — «Новая тема», в меню темы — «Новая лекция». Иконку и цвет любой папки меняет «⋯ → Иконка и цвет».
- **Лекция** — вкладки «Конспект и презентация» (тетрадка и PDF рядом), «Сводки ИИ», «Тесты», «Знание» (% выученных карточек).
- **«Сегодня»** открывается при запуске: заметка дня + стрик, что повторить, последние лекции. При возврате из другого приложения открывается последняя заметка.
- **Разделение экрана:** кнопка ◫ в шапке документа открывает его справа; разделитель перетаскивается, × закрывает.
- **Корзина:** удалённое хранится 30 дней («Корзина» внизу боковой панели).
- **Настройки:** тема (как в системе / светлая / тёмная), шрифт, ИИ-провайдер (Gemini или Claude) и ключ — ключ хранится только на этом устройстве и не попадает в резервную копию.
- **Место:** при заполнении 80% хранилища (или когда свободно < 300 МБ) на «Сегодня» появляется предупреждение.

> ⚠️ Данные живут в браузере, где открыто приложение. Встроенная панель браузера в Claude Code — только для проверки: при перезапуске её хранилище может очиститься. Для учёбы используйте приложение, установленное на iPad, и регулярно сохраняйте резервную копию.

## Запуск на компьютере

```bash
npm install
npm run dev      # http://localhost:5174 (и адрес в локальной сети — для iPad)
npm test         # тесты парсера карточек и логики повторения
npm run build    # production-сборка в dist/
```

## Установка на iPad

1. Задеплойте на GitHub Pages (ниже) и откройте адрес в Safari.
2. «Поделиться» → «На экран Домой».
3. Откройте приложение с иконки один раз при наличии сети — дальше оно работает полностью офлайн.

## Деплой на GitHub Pages

1. На github.com создайте **пустой публичный** репозиторий (например, `melkin`) — без README и .gitignore.
2. В терминале в папке проекта:
   ```bash
   git remote add origin https://github.com/<логин>/melkin.git
   git push -u origin main
   ```
   При первом push GitHub попросит войти: логин и **токен** вместо пароля (Settings → Developer settings → Personal access tokens), либо войдите через GitHub Desktop.
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` прогонит тесты, соберёт проект с адресом `/<имя-репозитория>/` и опубликует его. Адрес: `https://<логин>.github.io/melkin/`.
5. Каждый следующий `git push` в `main` обновляет сайт. В открытом приложении появится плашка «Доступна новая версия» — нажмите «Обновить».

### Перенос данных

Данные хранятся в браузере **отдельно для каждого адреса**: у `localhost:5174` на Mac, у сайта на GitHub Pages и у приложения на iPad — свои базы. Чтобы перенести конспекты: «Настройки и копии» → «Сохранить копию» (.zip) на старом месте → «Восстановить из файла» на новом.

### Офлайн

После первого открытия сайта приложение сохраняется целиком (≈7 МБ: интерфейс, шрифты KaTeX, pdf.js) и дальше работает без интернета. На iPad установите его через «Поделиться → На экран „Домой“» — так iPadOS не удалит данные.

## Синтаксис

**Карточки (как в RemNote)**

| Ввод | Что получится |
|---|---|
| `вопрос >> ответ` | карточка вперёд; `<<` — обратная, `<>` — в обе стороны |
| `понятие :: определение` | понятие (в обе стороны, выделено стилем) |
| `свойство ;; значение` | описание понятия-родителя: «Понятие → свойство?» |
| `вопрос >>>` | ответ — все вложенные блоки |
| `вопрос >>1.` | список: пункты открываются по одному |
| `вопрос >>A)` | выбор ответа: первый вложенный блок — верный |
| `{{скрыто}}`, `{{c1::…}}` | клоз; c1, c2 объединяют клозы в одну карточку |
| картинка → «⋯» → «Закрыть области» | image occlusion: каждая область — карточка; режимы «Скрыть одну» / «Скрыть все» |

Вложенные блоки (включая картинки, код и рисунки) всегда входят в ответ. Значок карточек справа от блока открывает панель: какие карточки создались, когда следующее повторение, сброс прогресса и отключение (история сохраняется).

**Заметки**

| Ввод | Что получится |
|---|---|
| `**жирный**` `*курсив*` `__подчёркнутый__` | форматирование (⌘B / ⌘I / ⌘U) |
| `==выделение==`, `=={green}…==` | выделение цветом |
| `# `, `## `, `### ` в начале блока | заголовки H1–H3 |
| `1. ` в начале блока | нумерованный пункт |
| `$x^2$`, `$$\int f$$` | формулы KaTeX |
| `$\ce{2H2 + O2 -> 2H2O}$` | химические формулы и реакции (mhchem): индексы, заряды `Fe^{3+}`, стрелки `->`, `<=>`; команда `/химия` |
| `[[Документ]]` | ссылка с автодополнением (нет такого — «Создать»); внизу документа — обратные ссылки |
| `#тег` | тег; «Теги» в боковой панели, страница тега — таблица блоков и их свойств |
| `((текст блока` | портал: живая копия блока, правка в портале меняет оригинал |
| `/` | меню вставки: картинка, блок кода, рисунок, портал, шаблон, свойства, заголовки, формула |
| ```` ```python ```` | блок кода с подсветкой (Python, C/C++, JS/TS, Java, MATLAB) |
| вставка/перетаскивание картинки | блок-картинка (большие фото уменьшаются до 2400 px) |
| Enter / Shift+Enter / Tab / Shift+Tab | новый блок / перенос строки / вложить / вынести |
| удерживать маркер блока или строку в дереве | перетаскивание |

**Повторение (SPEC 3).** Две кнопки — «Знаю» и «Не знаю».
- «Знаю»: интервал растёт по лестнице 15 мин → 1 ч → 1 день → 3 дня → 1 неделя → дальше вдвое.
- «Не знаю»: карточка вернётся через ~30 секунд среди других, пока не нажмёте «Знаю»; тогда интервал откатится на 4 шага (не ниже первого).
- Двусторонние карточки (`::`, `<>`) открываете и сравниваете сами; для остальных можно написать свой ответ текстом или Pencil (проверку ИИ добавим на этапе ИИ).
- Режимы: «Всё на сегодня», по предмету/теме/лекции и **экспресс-повтор** перед экзаменом (все карточки подряд, график не меняется). Лимита новых карточек нет.
- «Статистика»: стрик, график повторений за 30 дней, знание по предметам и темам, прогноз готовности.

Клавиши: пробел — показать ответ, 1 — «Не знаю», 2 или пробел — «Знаю», Z — отменить ответ.

## Apple Pencil

- **Рукописные блоки** (`/draw`, `/` → «Рукописный блок») и **тетради** — листы A4 без ограничения числа. Новый лист добавляется кнопкой «+» или сам, когда пишете на последнем/предпоследнем листе (в конце всегда остаётся один чистый).
- Инструменты: ручка (5 толщин), маркер-выделитель (3 толщины), палитра (20 цветов + «Любой цвет…»), **пипетка** (коснитесь штриха — возьмёт его цвет), ластик по штриху, **лассо**, текст, отмена/повтор.
- **Автофигуры:** проведите линию, круг, эллипс, прямоугольник, треугольник или стрелку и задержите Pencil на полсекунды — фигура выровняется. Выключаются кнопкой с фигурами рядом с толщинами.
- **Лассо:** обведите штрихи, тексты и картинки → тяните рамку, чтобы перенести, круглую ручку в углу — чтобы масштабировать; меню над рамкой: удалить, копия, перекрасить в цвет ручки.
- **Текст на листе:** инструмент «T» → коснитесь места на листе и печатайте (или пишите Scribble). Касание блока выделяет его: перетащить, ручка в углу — ширина, A−/A+ — размер, повторное касание — правка.
- **Вид листа** (кнопка над листом): фон — чистый, клетка, мелкая клетка, линейка, широкая линейка, точки, Корнелл, нотный стан; цвет бумаги и цвет линий отдельно; можно сразу для всех листов.
- **Вставить** («+» на панели): фото с камеры, картинка из «Фото»/«Файлов», **скан доски или слайда** — углы находятся сами (их можно подвинуть), перспектива выпрямляется, фон выравнивается до белого («Улучшить», «Ч/Б документ» или «Как есть»). Поверх фото можно писать.
- **Экспорт тетради в PDF** (там же): штрихи и фон векторами, картинки и текст; пустые листы в конце не попадают.
- Рисует только Pencil (на Mac — мышь); пальцы прокручивают, двумя пальцами — масштаб тетради. Листание — стрелками на панели.
- Далёкие листы тетради не рисуются, пока до них не докрутишь; исписанный лист (3000 штрихов) не тормозит — штрихи рисуются блоками.
- **Scribble:** коснитесь блока кончиком Pencil и пишите — iPadOS переведёт почерк в текст.

## PDF

- Импорт: «Импорт PDF, PowerPoint или фото» в меню боковой панели, кнопка «Загрузить презентацию» в лекции или `/pdf` в заметке. Файл хранится в базе и входит в резервную копию.
- **PowerPoint (.pptx)** превращается в PDF упрощённо: текст (настоящий — его можно выделять и искать), картинки, заливки, таблицы, списки; без анимаций и точной вёрстки. Для точного вида сохраните презентацию как PDF в PowerPoint/Keynote. Оригинал .pptx хранится рядом. Старый .ppt не читается.
- **Фото** слайдов или доски (можно сразу несколько) становятся «презентацией» — по странице на фото.
- Просмотр: миниатюры страниц, поиск по тексту, масштаб (кнопки, щипок, трекпад).
- **Текст:** выделите фрагмент → цвет выделения, «В конспект» (цитата со ссылкой «стр. N») или «Карточка» (вопрос `>>` фрагмент; без вопроса — клоз). Нажатие на выделение — сменить цвет, удалить, открыть блок.
- **Перо:** рукописные пометки поверх страниц (отдельный слой, сам PDF не меняется) — все инструменты тетради: ручки, маркер, палитра, пипетка, автофигуры, лассо с масштабом.
- **Область:** обведите схему или формулу → картинка в конспект или сразу карточки image occlusion.
- Конспект для выделений выбирается один раз (кнопка в панели) и запоминается для каждого PDF.
- Кнопка ⬇ — экспорт копии PDF с выделениями и пометками.

## Ежедневные заметки и шаблоны

- «Сегодня» в боковой панели открывает заметку текущего дня (создаётся автоматически, папка «Ежедневные заметки»).
- Любой документ можно сделать шаблоном (меню «⋯» → «Сделать шаблоном») и вставлять командой `/шаблон`. Карточки внутри шаблона не повторяются, в копиях — работают.
- Встроенные шаблоны: **«Лекция»** (тема, главное, подтемы, термины, формулы, вопросы, что спросить) и **«Сводка по теме»** — тоже через `/шаблон`.

## Поиск

Ищет по названиям, тексту заметок, выделениям в PDF, **полному тексту PDF и презентаций** (индекс строится в фоне при импорте и хранится офлайн), текстовым блокам на листах тетрадей и распознанному рукописному тексту (поле заполнится на этапе ИИ). Нажатие на результат открывает нужную страницу или лист.

## Тесты

- Вкладка «Тесты» в лекции и раздел «Тесты» на странице темы или предмета.
- **Из карточек** — работает без ИИ и без сети: выбор ответа, верно/неверно, сопоставление, несколько правильных, порядок (карточки-списки `>>1.`), подписи на картинке (области с подписями от ИИ), открытые вопросы и клозы.
- **ИИ: по подтеме / по всей лекции** — вопросы по материалу лекции, все 7 типов; «подпишите части» строится по реальному слайду.
- Ввод на iPad: варианты — крупные кнопки; сопоставление и подписи — перетащите фишку пальцем или Pencil (или коснитесь фишки, потом места); порядок — тяните за ⋮⋮ или стрелками; открытый ответ — текстом, Scribble или Pencil.
- После теста — балл и разбор каждой ошибки: ваш ответ, правильный, объяснение. Открытые ответы проверяет ИИ, без сети — вы сами.
- «Карточки из ошибок» → экран одобрения → карточки в «Сводках» лекции или в заметке «Ошибки из тестов» темы.
- Процент знания темы: карточки — 70%, последние результаты тестов — 30%.

## ИИ

Ключ вводится в «Настройках» (Gemini — бесплатный Flash, или Claude API) и хранится только на устройстве, в копию не попадает. Из России Gemini работает через VPN; при ошибке приложение пишет, что случилось: нет сети, нужен VPN, исчерпан лимит, неверный ключ. Ответы кэшируются — одинаковый запрос не тратит лимит повторно.

- **Сводки ИИ** (вкладка лекции): «Разбить на темы» → ИИ предлагает темы и подтемы со слайдами → правите названия, порядок, слайды → «Сохранить разбивку». Дальше по каждой подтеме: «Сводка» (коротко или «подробно, как конспект»), простым языком, с цветными выделениями. Картинки — со слайдов, из Wikimedia Commons и схемы ИИ; схема рисуется **только** по реальному слайду, под каждой картинкой — источник. Сводки лежат в обычной заметке «Сводки» — её можно править.
- **Карточки от ИИ**: кнопка «Карточки» у подтемы → экран одобрения (снять, поправить, удалить) → «Добавить».
- **ИИ-ручка**: лассо → обведите фрагмент в тетради или поверх PDF → «Объяснить» или «Перевести». Если обвели место без своих штрихов (например, текст слайда), появляется то же меню. Ответ можно «Вставить на лист».
- **Спросить ИИ** (в боковой панели и ✦ в шапке документа): текстом или **от руки**; можно с учётом открытого документа; ответ — «В заметку дня».
- **Распознавание рукописи**: листы тетрадей и рукописные блоки распознаются в фоне через 20 с после правки (выключается в настройках) или вручную («+» → «Распознать рукопись»). Текст ищется офлайн и идёт в сводки.
- **В повторении**: свой ответ (текстом или Pencil) → «Проверить» — ИИ сравнивает по смыслу и подсвечивает подходящую кнопку; без сети — проверяете сами. «Объясни проще» под ответом. В редакторе областей картинки — «Найти подписи»: ИИ сам закрывает подписи.
- **Язык**: русский материал → всё по-русски; английский → наполовину английский; английский технический предмет → по-русски; китайский → наполовину китайский.
- Промпты лежат в `src/features/ai/prompts/*.md` — их можно править без изменения кода.

## Резервные копии

- Раз в день при открытии (если что-то изменилось) сверху появляется «Сохранить копию» → меню «Поделиться» → «Сохранить в Файлы» → iCloud Drive. Имя файла всегда одно — **`Мелькин-копия.zip`**, поэтому новая копия заменяет старую (iOS спросит «Заменить?» — нажмите «Заменить»). «×» — не напоминать сегодня.
- То же вручную: «Настройки» → «Сохранить копию». Восстановить: «Настройки» → «Восстановить из файла» (заменить всё или объединить).
- В копию входят заметки, тетради, карточки, история, тесты, словарь терминов, картинки и PDF. Не входят: ключ ИИ, кэш ответов ИИ, индекс текста PDF и китайский словарь — они пересоздаются.

## Напоминания

- **Без настройки**: при открытии приложения (и при возвращении после часа перерыва) сверху — «Пора повторить N карточек».
- **Push-уведомления** даже при закрытом приложении: нужен свой бесплатный сервер на Cloudflare — пошагово в [`docs/PUSH.md`](docs/PUSH.md). Сервер получает только время повторений. Код сервера — `worker/worker.js`.

## Словарь терминов

- Термины собирает ИИ при сводках лекций (с переводом на китайский), сюда же попадают карточки «понятие :: определение»; можно добавить и поправить вручную («Словарь» в боковой панели).
- В заметках и сводках термины подчёркнуты пунктиром (с учётом окончаний: «митоза», «митозе»). Нажатие — определение офлайн, китайский перевод и источник.

## Китайский

- «Словарь» → «Китайский словарь» → «Загрузить» — **CC-CEDICT** (125 тыс. слов, открытая лицензия CC BY-SA 4.0, ~4 МБ, дальше работает офлайн). Определения в нём английские; «По-русски (ИИ)» переводит их.
- Можно импортировать свой словарь в формате **DSL** (GoldenDict/Lingvo) — например, китайско-русский **БКРС**, если вы скачали его сами для личного пользования. Файл читается на устройстве и в приложение не встраивается.
- Выделите китайский текст в заметке, сводке или PDF → «汉 Перевод»: слова (2–3 иероглифа) — по словарю с пиньинем, предложения — «Перевести предложение (ИИ)».
- «Trainchinese ↗» открывает слово в поиске Trainchinese (у приложения нет открытой ссылки на слово, поэтому открывается сайт).

## Структура

- `src/db` — схема Dexie (версии и миграции в `db.ts` / `migrations.ts`), резервные копии
- `src/features/notes` — дерево документов, outliner, форматирование, поиск
- `src/features/links` — ссылки `[[…]]`, обратные ссылки, теги (этап 2)
- `src/features/cards` — парсер карточек и синхронизация с блоками
- `src/features/review` — лестница интервалов, очередь, экран повторения, статистика
- `src/features/ink` — холст (perfect-freehand), рукописные блоки, тетради
- `src/features/pdf` — просмотр и аннотации PDF, импорт PPTX и фото, индекс текста
- `src/features/tests` — модель вопросов, тест из карточек, генерация ИИ, экран теста и разбор
- `src/features/glossary` — словарь терминов; `src/features/zh` — китайский словарь; `src/features/push` — напоминания (сервер — `worker/`)
- `src/features/ai` — клиент ИИ (Gemini/Claude), промпты, сводки, карточки, распознавание, проверка ответов
- `src/components` — главная, настройки, диалоги, иконки
