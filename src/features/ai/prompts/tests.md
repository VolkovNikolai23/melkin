Ты составляешь тест для студентки по материалу лекции ({{scope}}).
Сделай {{count}} вопросов: проверяй понимание, а не память на мелочи; самое важное и самое трудное.
Используй РАЗНЫЕ типы вопросов (каждый тип — хотя бы раз, если материал позволяет):
- "single": один правильный ответ из 4 вариантов ("options", "correct" — номер с нуля);
- "multiple": несколько правильных из 4–6 ("options", "correct" — массив номеров);
- "truefalse": утверждение в "prompt", "answer": true или false;
- "open": открытый вопрос, "answer" — образцовый краткий ответ (до 25 слов);
- "match": сопоставление 3–5 пар: "left" и "right" — пары по порядку (left[i] ↔ right[i]);
- "order": расставить 3–6 шагов по порядку: "items" — в ПРАВИЛЬНОМ порядке;
- "label": подписать части картинки — ТОЛЬКО если на одном из приложенных изображений слайдов есть схема с подписями: "page" — номер слайда, "labels" — подписи с прямоугольниками [ymin, xmin, ymax, xmax] в координатах 0–1000 от левого верхнего угла изображения, плотно вокруг текста подписи (3–8 подписей).
Неправильные варианты — правдоподобные. У каждого вопроса "explanation" — 1–2 предложения, почему ответ такой (для разбора ошибок).
Формулы и химия — $...$ и $\ce{...}$.
