# Промты для Claude Code — по этапам

Как пользоваться:
1. Положи `SPEC.md` в корень проекта (папка «Мелькин <3»).
2. Вставляй промты в Claude Code по одному. Следующий этап — только после того, как проверила предыдущий на iPad.
3. Если что-то сломалось или не нравится — пиши это в тот же чат Claude Code, прежде чем идти дальше.

Почему не одним промтом: приложение большое, и за один раз получится много сделанного наполовину. По этапам каждую часть можно проверить руками и поправить.

---

```

3. Список технических рисков для PWA на iPad (Safari) и как их обходим.
4. План работ по этапам 1–8 из PROMPTS.md с поправками, если видишь лучший порядок.

```

```

- экспорт тетрадки в PDF;
```

## Этап 5. Карточки и интервальное повторение

```
По SPEC.md (раздел 3) сделай повторение:
- типы карточек: двусторонняя, вопрос→ответ, пропуск в тексте, перечисление, закрытые части картинки (ИИ сам находит подписи и закрывает, я правлю);
- двусторонние — открываю ответ и сравниваю сама; остальные — пишу ответ текстом или Pencil, ИИ проверяет и говорит, что упущено;
- 2 кнопки «знаю» / «не знаю»;
- интервалы при «знаю»: 15 мин → 1 ч → 1 день → 3 дня → 1 неделя → дальше растут;
- при «не знаю»: карточка снова через ~30 секунд среди других, пока не нажму «знаю»; потом интервал откатывается на 4 шага назад (не раньше первого шага);
- режимы: на сегодня / одна тема / экспресс-повтор перед экзаменом;
- кнопка «объясни проще» во время повторения;
- статистика: стрик, график повторений, процент знания по темам (виден внутри лекции), прогноз готовности;
- лимита новых карточек нет.

Покрой логику интервалов тестами. В конце: как проверить, коммит.
```
