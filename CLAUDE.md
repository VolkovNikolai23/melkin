# Мелькин <3 — офлайн-аналог RemNote для iPad

## Цель
Личное приложение для учёбы (линейная алгебра, матанализ и др.): конспекты, карточки, интервальное повторение, рукописный ввод Apple Pencil и работа с PDF. Работает полностью офлайн на iPad, без подписок и серверов. По функциям и синтаксису ориентируемся на RemNote.

## Платформа и стек
- **PWA**, ставится на iPad через Safari → «На экран Домой». Основная цель — Safari на iPadOS (последние версии), ландшафт и портрет.
- Vite + React + TypeScript.
- `vite-plugin-pwa` (Workbox): precache всех ресурсов, включая шрифты KaTeX и worker pdf.js; после первой загрузки всё работает без сети.
- **Хранение:** IndexedDB через Dexie, без бэкенда. Картинки, PDF и рукописные данные хранятся как Blob. Вызвать `navigator.storage.persist()`, показывать занятое место (`navigator.storage.estimate()`).
- **Формулы:** KaTeX (шрифты бандлить локально).
- **Повторение:** `ts-fsrs`.
- **Рукописный ввод:** Pointer Events + `perfect-freehand`; штрихи хранить векторно (x, y, pressure).
- **PDF:** `pdfjs-dist` (worker в бандле).
- **Подсветка кода:** Prism или Shiki (бандл только нужных языков: Python, C/C++, JS/TS, Java, MATLAB).
- **Хостинг:** GitHub Pages (`base` в Vite + GitHub Actions workflow).
- **Язык интерфейса:** русский.

## Функции версии 1

### 1. Заметки
- Дерево папок и документов в боковой панели (drag & drop для перемещения).
- **Outliner:** каждый блок (Rem) — отдельная сущность с id. Enter — новый блок, Tab / Shift+Tab — вложить/вынести, сворачивание, перетаскивание блоков.
- **Форматирование:** жирный, курсив, подчёркнутый, выделение цветом, заголовки H1–H3, списки.
- **LaTeX:** inline `$...$` и блочный `$$...$$`, рендер KaTeX вне режима редактирования.
- **Картинки:** вставка из «Фото», «Файлов», буфера обмена, drag & drop; масштаб по ширине.
- **Блоки кода** с подсветкой и выбором языка (```` ``` ````).
- **Ссылки** `[[название]]` с автодополнением (создание нового документа или блока, если не найден), переход по нажатию. **Обратные ссылки** — панель внизу документа или блока.
- **Теги** `#тег`, фильтр по тегу.
- **Свойства и таблицы:** блоку можно задать свойства (поле → значение); документ-тег показывается как таблица всех блоков с этим тегом и их свойствами.
- **Порталы:** вставка живого блока из другого места (`((` или команда `/portal`), редактирование в портале меняет оригинал.
- **Ежедневные заметки:** документ на каждый день, создаётся автоматически, кнопка «Сегодня».
- **Шаблоны:** документ-шаблон (структура блоков), вставка через `/template`.
- **Поиск** по всем заметкам (включая текст карточек и названия PDF).
- **Слэш-меню** `/` для вставки: картинка, код, рисунок, портал, шаблон, PDF, заголовок и т. д.

### 2. Карточки (синтаксис как в RemNote)
- `вопрос >> ответ` — в одну сторону; `<<` — обратная; `<>` — в обе стороны.
- `понятие :: определение` — **понятие** (двусторонняя карточка, понятие выделено стилем).
- `свойство ;; значение` — **описание** (descriptor): внутри родителя-понятия, вопрос вида «Понятие → свойство?».
- **Многострочный ответ:** `вопрос >>>` — ответом служат все дочерние блоки.
- **Карточка-список:** `вопрос >>1.` — ответ — упорядоченный список дочерних блоков (показывать пункты по одному).
- **Множественный выбор:** `вопрос >>A)` — первый дочерний блок — правильный ответ, остальные — неправильные, варианты перемешиваются.
- **Клозы** `{{...}}` — каждая группа = отдельная карточка (поддержать `{{c1::...}}` для группировки).
- **Image occlusion:** на картинке рисуются прямоугольники, каждый — карточка («скрыть один / скрыть все»).
- Формулы, картинки, код и рукописные блоки работают и в вопросе, и в ответе.
- При правке блока карточки обновляются; история повторений сохраняется, если карточка та же (стабильный id).
- Возможность временно отключить карточку блока, не удаляя текст.

### 3. Повторение (FSRS)
- Экран «Повторить»: очередь на сегодня — все карточки или по документу/папке/тегу.
- Вопрос → «Показать ответ» → Снова / Трудно / Хорошо / Легко (с подписью следующего интервала).
- Лимит новых карточек в день (по умолчанию 20).
- Счётчик карточек к повторению на главном экране и у каждого документа.
- Из карточки — переход к исходному блоку.

### 4. Apple Pencil и PDF
- **Рукописный блок** внутри заметки и в ответе карточки.
- **Тетради:** отдельный тип документа, страницы для письма (фон: чистый / клетка / линейка), листание и масштаб.
- **Инструменты:** перо (толщины, цвета), маркер, ластик (по штриху), лассо (выделить → перенести/удалить), отмена/повтор.
- Чувствительность к нажиму. **Отсечение ладони:** рисует только `pointerType === "pen"`, пальцы — прокрутка и масштаб. `touch-action: none` на холсте.
- **PDF:** импорт PDF в документ; просмотр с миниатюрами страниц и поиском по тексту.
- **Аннотации PDF:** выделение текста цветом и рукописные пометки Pencil поверх страниц (хранить отдельным слоем, сам PDF не менять); экспорт PDF с аннотациями — по возможности.
- **Выделения → заметки и карточки:** выделенный фрагмент можно отправить в документ как блок со ссылкой на страницу PDF и сразу сделать из него карточку (в том числе выделить область страницы как картинку для image occlusion).
- **Распознавание рукописного текста:**
  - для ввода текста использовать системный Scribble iPadOS (пишешь Pencil прямо в текстовые поля). Проверить, что редактор блоков с ним совместим;
  - конвертация существующего рукописного блока в текст — экспериментально, только офлайн-решение (например, небольшая ONNX/TF.js-модель). Если качественного офлайн-варианта нет — оставить заглушку и сообщить. Делать последним.

### 5. Резервные копии
- Экспорт всей базы в один файл (`.zip`: JSON + картинки + PDF) через share sheet / «Сохранить в Файлы».
- Импорт из файла (замена или слияние, с подтверждением).
- Напоминание, если копии не было более 7 дней.

## Не в версии 1
Режим экзамена, статистика и графики, настройка параметров FSRS, импорт из Anki/Markdown, синхронизация между устройствами, граф связей, ИИ-функции, совместный доступ, плагины.

## Дизайн
Чистый и спокойный, удобный для пальцев и Pencil (зоны нажатия ≥ 44px), светлая и тёмная темы по системе, сворачиваемая боковая панель.

## Этапы
1. **Каркас:** проект, PWA, схема Dexie (с миграциями), дерево документов, outliner, форматирование, LaTeX, поиск, экспорт/импорт.
2. **Богатые заметки:** картинки, код, слэш-меню, ссылки и обратные ссылки, теги, свойства и таблицы, порталы, ежедневные заметки, шаблоны.
3. **Карточки:** парсер всего синтаксиса, image occlusion, синхронизация карточек с блоками.
4. **Повторение:** FSRS, экран повторения, очереди, счётчики.
5. **Apple Pencil:** рукописные блоки, тетради, лассо, совместимость со Scribble.
6. **PDF:** просмотр, выделения, рукописные аннотации, выделения → блоки и карточки.
7. **Деплой и полировка:** GitHub Pages, проверка офлайн-режима на iPad, производительность на больших документах.
8. **Эксперимент:** распознавание рукописного текста.

После каждого этапа приложение должно запускаться (`npm run dev`); коротко описать, что сделано и как проверить. Тесты (Vitest) для парсера карточек, ссылок и логики повторения.

## Правила для кода
- Готовый к использованию код, без заглушек в ключевой логике.
- Структура: `src/db`, `src/features/notes`, `src/features/links`, `src/features/cards`, `src/features/review`, `src/features/ink`, `src/features/pdf`, `src/components`.
- Комментарии на русском там, где логика неочевидна.
- Схема БД версионируется (миграции Dexie), обновления не теряют данные.
- Следить за производительностью: виртуализация длинных документов и списков PDF-страниц.
