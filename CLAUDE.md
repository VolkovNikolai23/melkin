# Мелькин <3 — офлайн-аналог RemNote для iPad

## Цель
Личное приложение для учёбы (линейная алгебра, матанализ и др.): конспекты + карточки + интервальное повторение + рукописный ввод Apple Pencil. Работает полностью офлайн на iPad, без подписок и серверов.

## Платформа и стек
- **PWA**, устанавливается на iPad через Safari → «На экран Домой». Основная цель — iPadOS Safari (последние версии), ландшафт и портрет.
- Vite + React + TypeScript.
- `vite-plugin-pwa` (Workbox): precache всех ресурсов; после первой загрузки приложение полностью работает без сети.
- **Хранение:** IndexedDB через Dexie. Никакого бэкенда. Вызвать `navigator.storage.persist()`.
- **Формулы:** KaTeX (шрифты бандлить локально, без CDN).
- **Повторение:** `ts-fsrs` (алгоритм FSRS).
- **Рукописный ввод:** Pointer Events + `perfect-freehand`; штрихи хранить как векторные данные (x, y, pressure).
- **Хостинг:** GitHub Pages (настроить `base` в Vite и GitHub Actions workflow для деплоя).
- **Язык интерфейса:** русский.

## Функции версии 1 (MVP)
### 1. Заметки
- Дерево папок и документов в боковой панели.
- Внутри документа — иерархические блоки (outliner): Enter — новый блок, Tab / Shift+Tab — вложить/вынести, сворачивание.
- Inline LaTeX `$...$` и блочный `$$...$$`, рендер KaTeX при выходе из редактирования блока.
- Поиск по всем заметкам.

### 2. Карточки из текста
- `вопрос :: ответ` → карточка (вперёд); `вопрос ;; ответ` → двусторонняя.
- Клозы `{{скрытый текст}}` — каждая группа = отдельная карточка.
- Дочерние блоки блока-вопроса входят в ответ (как в RemNote).
- При правке блока карточки обновляются, история повторений сохраняется, если карточка та же.

### 3. Повторение (FSRS)
- Экран «Повторить»: очередь на сегодня (все или по документу/папке).
- Вопрос → «Показать ответ» → Снова / Трудно / Хорошо / Легко (с подписью следующего интервала).
- Лимит новых карточек в день (по умолчанию 20).
- Счётчик карточек к повторению на главном экране.

### 4. Apple Pencil
- **Рукописный блок** внутри заметки и внутри ответа карточки (кнопка «+» или команда `/draw`).
- **Тетради** — отдельный тип документа: страницы для письма (фон: чистый / клетка / линейка).
- Инструменты: перо (2–3 толщины, несколько цветов), маркер, ластик (по штриху), отмена/повтор.
- Чувствительность к нажиму. **Отсечение ладони:** рисует только `pointerType === "pen"`, пальцы — прокрутка/масштаб.
- `touch-action: none` на холсте, отключить системное выделение.

### 5. Резервные копии
- Экспорт всей базы в один `.json` («Сохранить копию» → share sheet / «Сохранить в Файлы»).
- Импорт из файла (с подтверждением: замена или слияние).
- Напоминание, если копии не было более 7 дней.

## Не в MVP (позже)
Ссылки между заметками и backlinks, импорт PDF с аннотациями, статистика, синхронизация с Mac, распознавание рукописного текста.

## Дизайн
Чистый и спокойный, удобный для пальцев и Pencil (зоны нажатия ≥ 44px), светлая и тёмная темы по системе, сворачиваемая боковая панель.

## Этапы
1. Каркас: Vite + React + TS + PWA, схема Dexie, дерево документов, outliner, KaTeX, экспорт/импорт.
2. Парсинг карточек, FSRS, экран повторения.
3. Apple Pencil: рукописные блоки и тетради.
4. Деплой на GitHub Pages, проверка офлайн-режима, полировка.

После каждого этапа приложение должно запускаться (`npm run dev`); коротко описать, что сделано и как проверить. Тесты (Vitest) для парсера карточек и логики повторения.

## Правила для кода
- Готовый к использованию код, без заглушек в ключевой логике.
- Структура: `src/db`, `src/features/notes`, `src/features/cards`, `src/features/review`, `src/features/ink`, `src/components`.
- Комментарии на русском там, где логика неочевидна.
- Схема БД версионируется (миграции Dexie), обновления не теряют данные.
