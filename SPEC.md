# ТЗ: учебное приложение (PWA для iPad)

Своё приложение для учёбы в духе RemNote, без подписки. Рукописные конспекты-тетрадки, загрузка презентаций, ИИ делает сводки, карточки и тесты, интервальное повторение.

- Главная цель: экзамены по биологии; дальше химия, позже физика и немного китайского.
- Сценарий: конспект от руки на паре + презентация преподавателя со своими пометками → карточки и тесты.
- Повторение: 15–30 минут в день.
- Платформа: PWA, основное устройство iPad (Safari, «На экран Домой»), Apple Pencil. На Mac та же PWA, отдельно, без синхронизации.
- Интерфейс полностью на русском.
- Всё из ТЗ одинаково важно; теги не нужны.

## 1. Загрузка материала и ИИ

- Провайдер ИИ абстрагирован. По умолчанию Google Gemini (Flash, бесплатный уровень), в настройках можно переключить на Claude API. Ключ вводится в настройках и хранится локально. Работа через VPN у пользователя.
- Форматы загрузки: PDF, PowerPoint (.pptx), фото слайдов и доски.
- ИИ сам делит материал на темы и подтемы, пользователь правит разбивку.
- Сводки: по умолчанию коротко (до полстраницы, только главное), переключатель «подробно, как конспект». Своими словами, максимально простым языком («как пятилетке»), не пересказ конспекта. Много цветов и выделений для зрительной памяти.
- Картинки в сводках: из презентации, из интернета, рисунки пользователя, схемы от ИИ. Реалистичные сгенерированные рисунки не нужны.
- Схемы от ИИ строятся ТОЛЬКО по реальному источнику (картинка из презентации или из конкретной статьи). Под каждой схемой и картинкой ссылка на источник для проверки (защита от галлюцинаций).
- ИИ сам определяет важное и сложное; пометки пользователя на это не влияют.
- Сгенерированные карточки сначала показываются на одобрение: оставить, изменить, удалить.
- ИИ-ручка: обвела фрагмент Pencil (в конспекте, PDF, учебнике) → перевод или объяснение именно этого места.
- Кнопка «объясни проще» во время повторения.
- Вопросы к ИИ можно писать от руки.
- Язык генерации:
  - материал на русском → всё на русском;
  - на английском → наполовину английский, наполовину русский;
  - английский технический предмет (например, информатика) → карточки на русском;
  - китайский → наполовину китайский, наполовину русский.

## 2. Тесты

- По каждому разделу и по всей теме.
- Типы вопросов (все 7): один ответ; несколько правильных; верно/неверно; открытый ответ; сопоставление; подписать части на картинке (обязательно); расставить по порядку.
- После теста разбор каждой ошибки с объяснением; ошибки автоматически становятся карточками.

## 3. Карточки и интервальное повторение

Цель: выучить быстро и запомнить надолго. Даты экзамена нет, лимита новых карточек нет.

| Тип | Как проверяется ответ |
| --- | --- |
| Двусторонняя (термин ↔ определение) | Открываю ответ, сравниваю сама |
| Вопрос → ответ | Пишу ответ (текст или Pencil), проверяет ИИ |
| Пропуск в тексте | Пишу ответ, проверяет ИИ |
| Перечисление списка | Пишу ответ, проверяет ИИ |
| Закрытые части картинки (image occlusion) | Пишу ответ, проверяет ИИ; подписи на картинке находит и закрывает ИИ, пользователь правит |

- Оценка: 2 кнопки, «знаю» / «не знаю».
- Интервалы при «знаю»: 15 минут → 1 час → 1 день → 3 дня → 1 неделя → дальше растут.
- При «не знаю»: карточка снова показывается примерно через 30 секунд среди других, повторяется, пока не нажата «знаю»; затем интервал откатывается на 4 шага назад (не раньше первого шага).
- Режимы: всё на сегодня; одна тема/раздел; экспресс-повтор перед экзаменом (всё подряд, без графика).
- Статистика: стрик, график повторений, процент знания по каждой теме (виден внутри лекции), прогноз готовности.
- Уведомления по интервалам: web push через маленький бесплатный сервер (основной вариант); запасной вариант — напоминания при открытии приложения.

## 4. Apple Pencil, тетрадки, PDF, медиа

- Конспект = тетрадка: свободный лист, текст/рисунки/вставки где угодно. Листов без ограничений; добавляются вручную или автоматически, когда пишу на последнем/предпоследнем.
- Экспорт тетрадки в PDF.
- Pencil работает: в заметках, в отдельных тетрадях, поверх PDF и презентаций, в ответах на карточки, в вопросах к ИИ.
- Распознавание рукописного текста через Gemini (онлайн); распознанный текст сохраняется для офлайн-поиска и для ИИ.
- Инструменты: ручки разной толщины и цвета (учёт нажима), маркер-выделитель, палитра, пипетка (взять цвет из уже написанного), лассо (выделить/переместить/масштабировать), ластик, автофигуры (провела линию или фигуру и задержала Pencil → выравнивается). Линейка не нужна.
- Фоны страниц: чистый, клетка, линейка, точки и др.; цвет листа и цвет линий настраиваются отдельно (белая, желтоватая, чёрная, розовая бумага…).
- PDF/презентации: писать и рисовать поверх, маркер, выделенный фрагмент → «сделать карточку» одной кнопкой.
- Фото доски/слайдов: автоматическое выпрямление и улучшение как у сканера.
- Камера: фото сразу вставляется в заметку.
- Аудиозапись лекций не нужна.

## 5. Организация и словарь

- Папки: Предмет → Тема → Лекция. Плюс автоматическая папка «Сегодня», открывается при запуске.
- Внутри лекции вкладки (как в RemNote): мой конспект + загруженная презентация; сводки и объяснения ИИ вложенными пунктами по подтемам; тесты по подтемам и по теме; процент знания темы.
- Нужны: ссылки между заметками (и обратные ссылки), порталы (фрагмент одной заметки внутри другой, синхронно), ежедневные заметки, шаблоны (например, «Лекция»), химические формулы и реакции (красиво).
- Словарь терминов: нажатие на термин → определение офлайн, с переводом на китайский.
- Китайский: слова (2–3 иероглифа) переводит офлайн китайско-русский словарь уровня БКРС (проверить лицензию данных БКРС); предложения переводит ИИ. Проверить, можно ли по выделенному слову открывать приложение Trainchinese (URL-схема); данные Trainchinese не копировать.

## 6. Дизайн и интерфейс

- Стиль уютный, милый, пастельный. Цвета: пастельные розовый и голубой, приглушённый винно-красный.
- Светлая и тёмная тема переключаются вместе с системой.
- Анимаций и мелких радостей (конфетти, реакции на правильный ответ, стрик) — чем больше, тем лучше.
- Папки: иконка из набора, цвет иконки/текста выбирается.
- Навигация: боковая панель слева (ориентиры RemNote, Notes Plus).
- Главный экран: слева папки и «Сегодня»; справа стрик, последние лекции, что повторить.
- При возврате из другого приложения открыта последняя заметка; после полного закрытия — «Сегодня».
- Горизонтальная и вертикальная ориентация.
- Шрифт выбирается в настройках.
- Разделение экрана внутри приложения (например, презентация слева, конспект или карточки справа).

## 7. Данные

- Всё хранится локально (офлайн-first); ИИ, распознавание и пуши требуют интернет.
- Резервная копия: раз в день при открытии кнопка «Сохранить копию» в iCloud Drive (share sheet) с одинаковым именем файла, новая заменяет старую. Плюс восстановление из копии.
- Корзина: восстановление удалённого в течение 30 дней.
- Хранилище: следить за объёмом; при приближении к лимиту заранее явно предупреждать.
- Не нужно: шаринг с одногруппниками, импорт из RemNote, пароль/Face ID.
