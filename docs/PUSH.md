# Напоминания о повторении (push) — как включить

Приложение может присылать уведомление «Пора повторить N карточек», даже когда оно закрыто. Для этого нужен маленький сервер, который в нужное время «будит» iPad. Мы используем **Cloudflare Workers** — это бесплатно, и программировать ничего не нужно: только скопировать и вставить.

**Что знает сервер:** только время, когда пора повторять (список чисел). Текст карточек, заметки и ключ ИИ на сервер не попадают.

**Если не настраивать сервер**, ничего не сломается: приложение само напоминает о повторении, когда вы его открываете.

Понадобится 10–15 минут, компьютер или iPad с браузером и почта.

---

## Шаг 0. Подготовка iPad

1. Откройте приложение в Safari, нажмите «Поделиться» → **«На экран Домой»**. Уведомления на iPad работают **только** у приложения, открытого с экрана «Домой» (iPadOS 16.4 или новее).
2. Дальше открывайте Мелькина значком с экрана «Домой».

## Шаг 1. Аккаунт Cloudflare

1. Зайдите на **dash.cloudflare.com** и нажмите **Sign up** (регистрация).
2. Укажите почту и пароль, подтвердите почту письмом.
3. Тариф — **Free**. Карта не нужна.

## Шаг 2. Создайте Worker (сам сервер)

1. В меню слева откройте **Workers & Pages** (или **Compute → Workers**).
2. Нажмите **Create** → **Create Worker** (или **Start with Hello World**).
3. Имя: `melkin-push`. Нажмите **Deploy**.
4. Нажмите **Edit code**.
5. Удалите весь текст в редакторе. Откройте в папке проекта файл **`worker/worker.js`**, скопируйте его целиком и вставьте в редактор.
6. Нажмите **Deploy** (справа вверху).
7. Вверху страницы Worker’а будет адрес вида `https://melkin-push.ваше-имя.workers.dev` — **сохраните его**, он понадобится в шаге 6.

## Шаг 3. Хранилище подписок (KV)

1. В меню слева: **Storage & Databases → KV** (или **Workers KV**).
2. **Create namespace** (Create instance) → имя `melkin-subs` → **Add**.
3. Вернитесь к Worker’у `melkin-push` → вкладка **Settings** → **Bindings** → **Add binding** → **KV namespace**.
4. **Variable name**: `SUBS` (большими буквами, ровно так). **KV namespace**: `melkin-subs`. Сохраните (**Deploy** / **Save**).

## Шаг 4. Ключи (VAPID)

1. В Мелькине: **Настройки → Напоминания → «Ключи для сервера» → «Сгенерировать ключи»**. Появятся две длинные строки.
2. В Cloudflare: Worker `melkin-push` → **Settings** → **Variables and Secrets** → **Add**. Добавьте три значения, тип — **Secret**:
   - `VAPID_PUBLIC` — строка «VAPID_PUBLIC» из приложения;
   - `VAPID_PRIVATE` — строка «VAPID_PRIVATE» из приложения;
   - `VAPID_SUBJECT` — `mailto:` и ваша почта, например `mailto:ivanova@mail.ru`.
3. Нажмите **Deploy** / **Save**.

> Закрытый ключ (VAPID_PRIVATE) никому не показывайте и никуда больше не вставляйте. Приложение его не хранит — если потеряете, просто сгенерируйте новую пару и повторите шаги 4 и 6.

## Шаг 5. Расписание (Cron)

1. Worker `melkin-push` → **Settings** → **Triggers** (Trigger events) → **Cron Triggers** → **Add**.
2. Впишите `*/15 * * * *` (каждые 15 минут) → **Add / Save**.

## Шаг 6. Включите уведомления в приложении

1. Мелькин (открытый с экрана «Домой») → **Настройки → Напоминания**.
2. **Адрес сервера** — адрес из шага 2 (`https://melkin-push….workers.dev`).
3. **Открытый ключ** — уже заполнен после генерации (или вставьте VAPID_PUBLIC).
4. Выберите час ежедневного напоминания.
5. Нажмите **«Включить уведомления»** и разрешите уведомления в окне iPad.
6. Нажмите **«Проверить»** — через несколько секунд придёт тестовое уведомление.

Готово. Уведомления приходят:
- когда подходят короткие шаги (15 минут, час) — в течение дня;
- раз в день в выбранный час, если к этому времени есть что повторить.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| «На iPad уведомления работают только в приложении, добавленном на экран Домой» | Откройте приложение значком с экрана «Домой», а не во вкладке Safari |
| «Уведомления не разрешены» | Настройки iPad → Уведомления → Мелькин → включить |
| «Сервер напоминаний недоступен» | Проверьте адрес из шага 2 (начинается с `https://`, без пробелов) и интернет |
| «Сервер ответил ошибкой 404» при «Проверить» | Включите уведомления заново (кнопка «Включить уведомления») |
| «Сервер ответил ошибкой 500» | Проверьте шаг 3 (имя `SUBS`) и шаг 4 (три секрета, без лишних пробелов) |
| Тест приходит, а обычные напоминания нет | Проверьте шаг 5 (Cron `*/15 * * * *`) |

**Бесплатного тарифа хватает с большим запасом**: 100 000 запросов в день, а приложение делает несколько десятков.

**Для тех, кто умеет пользоваться терминалом**: в папке `worker` есть `wrangler.toml` — можно развернуть командой `npx wrangler deploy` (впишите id своего KV и добавьте секреты через `npx wrangler secret put VAPID_PUBLIC` и т. д.).
