# Как обновлять приложение на iPad

Приложение живёт на GitHub Pages. Обновление — это новая версия кода на GitHub, а iPad сам её подтягивает. **Ваши данные (конспекты, карточки, тетради) при обновлении не теряются**: они хранятся на iPad отдельно от кода.

## Обычное обновление (после правок в коде)

1. **Перед большим обновлением сохраните копию:** «Настройки» → «Сохранить копию» (или баннер «Сохраните копию на сегодня») → «Сохранить в Файлы» → iCloud Drive.
2. Отправьте изменения на GitHub. В терминале в папке проекта:
   ```bash
   git push
   ```
   (Если правки делает Claude Code — попросите его: «закоммить и запушь».)
3. Подождите 2–3 минуты: GitHub сам прогонит тесты и опубликует новую версию. Ход можно посмотреть в репозитории на вкладке **Actions** (зелёная галочка — готово, красный крестик — ошибка, версия не опубликована, старая продолжает работать).
4. На iPad откройте Мелькина значком с экрана «Домой» **при включённом интернете**. Через несколько секунд внизу появится плашка **«Доступна новая версия» → «Обновить»**. Нажмите — приложение перезапустится уже новым.
5. Если плашка не появилась: закройте приложение (смахните вверх из переключателя приложений) и откройте снова, с интернетом.

## Если что-то пошло не так

| Ситуация | Что сделать |
|---|---|
| Плашка не появляется долго | Проверьте на GitHub → Actions, что сборка зелёная. Закройте и откройте приложение с интернетом |
| После обновления пропали данные | Скорее всего, открыт другой адрес (например, не тот репозиторий). Откройте тот же адрес, что и раньше. Если данные правда пропали — «Настройки» → «Восстановить из файла» → копия из iCloud Drive |
| Приложение «зависло» на старой версии | Настройки iPad → Safari → Дополнения → Данные сайтов — **не удаляйте** данные сайта Мелькина (там конспекты!). Вместо этого просто подождите и откройте приложение повторно с интернетом |
| Новая версия работает хуже | Откатите правку на GitHub (или попросите Claude Code), сделайте `git push` — через пару минут вернётся прошлая версия |

## Важно

- **Адрес не меняйте.** Данные привязаны к адресу сайта (`https://<логин>.github.io/melkin/`). Другой адрес — пустое приложение.
- **Не удаляйте значок с экрана «Домой» и данные сайта** — вместе с ними удалятся конспекты. Если всё же нужно переустановить: сначала сохраните копию, потом восстановите её.
- Китайский словарь после переустановки загрузите заново («Словарь» → «Китайский словарь» → «Загрузить»), ключ ИИ — вставьте заново (они не входят в копию).

## Mac

Та же PWA работает на Mac **отдельно**, без синхронизации с iPad:
- **Safari** (macOS 14 Sonoma и новее): откройте адрес → меню **«Файл» → «Добавить в Dock»**.
- **Chrome / Edge**: значок установки в адресной строке (или меню → «Установить приложение»).

У приложения на Mac своя база. Перенести конспекты: на iPad «Сохранить копию» → на Mac «Восстановить из файла» (и наоборот). Рисовать на Mac можно мышью или трекпадом, масштаб — щипком трекпада.
